Q1

解决什么问题Problem

✕ 常见换肤方式Typical reskinning

  • 补丁 DOM / 注入 JS — 官方一更新就失效，且有安全面DOM patches / injected JS — breaks on updates, adds attack surface
  • 替换背景媒体 — 包体大、加载慢、观感不可控Background media swaps — heavy and unpredictable
  • 随手配色 — 灰阶、边框、状态色各写各的，没有体系Ad-hoc colors — grays, borders and states with no system

✓ 本皮肤包This pack

  • L1 纯 token — 只重映射官方语义变量，官方更新自动兼容L1 pure-token — remaps official semantic vars; survives updates
  • 每套 60+ token — surfaces / 四级边框 / 四级文字灰阶 / 状态色 / 阴影全覆盖60+ tokens per skin — surfaces, 4-level borders & grays, states, shadows
  • theme-agnostic — 色卡即完整观感，明暗模式一致theme-agnostic — the palette is the look, in both modes
